# 제주 감귤 당도 예측 웹앱 — 실행 및 배포 가이드

> 8차시 프로젝트 ② 최종 결과물 · Streamlit 방식

## 폴더 구성

```
08_프로젝트2_감귤당도예측/
├─ app.py                 ← 웹앱 코드 (Python만 사용)
├─ requirements.txt       ← 필요한 라이브러리 목록 (배포 서버가 자동 설치)
├─ data/
│   ├─ seongsan_weather.csv   ← 성산 기상 자료 (기상청, cp949)
│   └─ citrus_brix.csv        ← 감귤 당도 측정 자료 (교재 제공, utf-8)
└─ 배포가이드.md          ← 이 문서
```

- 앱은 **`app.py`와 같은 위치의 `data/` 폴더**에서 데이터를 읽는다. 폴더 구조를 바꾸지 않는다.
- 모델은 앱이 켜질 때 데이터로 바로 학습한다(1초 이내). 따로 모델 파일을 올릴 필요가 없다.

## 1. 내 컴퓨터에서 실행해 보기

1. 명령 프롬프트(또는 터미널)를 열고 이 폴더로 이동한다.
   ```
   cd 08_프로젝트2_감귤당도예측
   ```
2. 라이브러리를 설치한다. (처음 한 번만)
   ```
   pip install -r requirements.txt
   ```
3. 앱을 실행한다.
   ```
   streamlit run app.py
   ```
4. 브라우저가 자동으로 열린다. 열리지 않으면 터미널에 나온 주소(`http://localhost:8501`)를 직접 연다.
5. 끝낼 때는 터미널에서 `Ctrl + C`.

> 오류 `FileNotFoundError: data/...` → 터미널의 현재 위치가 이 폴더인지, `data/` 폴더에 CSV 두 개가 있는지 확인한다.

## 2. GitHub 저장소 만들기

1. [github.com](https://github.com)에 로그인 → 오른쪽 위 **+** → **New repository**
2. 저장소 이름 예: `citrus-brix-app` · **Public** 선택 → **Create repository**
3. **uploading an existing file** 을 눌러 `app.py`, `requirements.txt`를 끌어다 놓는다.
4. `data` 폴더는 **폴더째** 끌어다 놓는다. (업로드 화면에서 `data/seongsan_weather.csv`처럼 경로가 보이면 성공)
5. 아래 **Commit changes** 를 누른다.
6. 저장소 첫 화면에 `app.py`, `requirements.txt`, `data/`가 보이는지 확인한다.

## 3. Streamlit Community Cloud에 배포하기

1. [share.streamlit.io](https://share.streamlit.io)에 접속 → **GitHub 계정으로 로그인**
2. **Create app** (또는 **New app**) → **Deploy a public app from GitHub**
3. 입력
   - Repository: 방금 만든 저장소 (예: `내아이디/citrus-brix-app`)
   - Branch: `main`
   - Main file path: `app.py`
   - App URL: 원하는 주소 이름을 정한다
4. **Deploy** 를 누른다. 처음에는 `requirements.txt`의 라이브러리를 설치하느라 몇 분 걸린다.

## 4. 배포 확인 체크리스트

- [ ] 왼쪽 메뉴 7개 페이지가 모두 오류 없이 열린다
- [ ] ③ 탐색 및 전처리의 그래프·표가 보인다 (데이터가 제대로 올라갔다는 뜻)
- [ ] ⑤ 모델 평가에서 차수 슬라이더를 움직이면 숫자와 그래프가 바뀐다
- [ ] ⑥ '당도 예측해 보기'에서 시기를 바꾸면 예측 당도가 바뀐다 (10월 기본값 ≈ 8.10°Bx)

## 5. 공유 링크 만들기

- 배포가 끝나면 브라우저 주소창의 주소가 곧 **공유 링크**다. 복사해서 발표 자료·보고서에 붙인다.
- 오른쪽 위 **Share** 버튼에서도 링크를 복사할 수 있다.

## 자주 생기는 문제

| 증상 | 원인과 해결 |
|---|---|
| `ModuleNotFoundError` | `requirements.txt`가 저장소 **맨 위 폴더**에 있는지 확인 |
| `FileNotFoundError: data/...` | `data` 폴더를 폴더째 올렸는지, 파일 이름 철자가 같은지 확인 |
| 한글이 깨진 표가 보임 | 기상 자료는 `cp949`로 읽도록 되어 있다. CSV를 엑셀에서 다시 저장하지 말고 원본을 올린다 |
| 앱이 "잠들어 있음(This app has gone to sleep)" | 한동안 아무도 접속하지 않으면 잠든다. **Yes, get this app back up!** 을 누르면 1분 안에 다시 켜진다 |
| 코드를 고쳤는데 그대로임 | GitHub의 `app.py`를 고치고 Commit하면 몇십 초 뒤 자동으로 다시 배포된다. 안 되면 앱 오른쪽 아래 **Manage app → Reboot** |
